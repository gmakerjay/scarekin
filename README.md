# บริษัท โบวี่สแคร์กิน จำกัด (BOWIE SCARESKIN CO., LTD.)
## ระบบสารสนเทศทางการบัญชีและคลังสินค้า (General Accounting & Inventory System)
**ช่วงเวลาบันทึกรายการบัญชี:** 24 สิงหาคม 2569 ถึง 30 ตุลาคม 2569 (รวม 68 วัน)  
**รูปแบบระบบ:** จำลองระบบบัญชีทั่วไปแบบ PEAK / FlowAccount ในรูปแบบสไตล์เว็บวินโดวส์คลาสสิก (HTML Table ยุค 90s / Windows XP / Retro Dark Web)

---

### จุดเด่นของระบบ
- **ข้อความชี้แจง:** โปรเจคนี้เป็นโปรเจคเพื่อนำส่ง / พรีเซ้นต์ในภาควิชาการบัญชีเท่านั้น ข้อมูลทุกอย่างคือการสมมติขึ้นมา
- **ฐานข้อมูลสินค้าสมมุติ 100 รายการครบถ้วน:** ครอบคลุมผลิตภัณฑ์เวชสำอางและสกินแคร์ (รหัสเรียบง่าย SK-01 ถึง SK-100) เช่น สกินแคร์ A1, ครีมบำรุง B1, เซรั่ม C1, โทนเนอร์ D1 พร้อมข้อมูลราคาทุน, ราคาขาย, อัตรากำไร, สต็อกยกมา, รับเข้า, จ่ายออก, สต็อกปลายงวด และจุดสั่งซื้อ (Reorder Point)
- **ระบบรายรับ (Sales & Income):** บันทึกรายการขาย 187 รายการ (รหัส INV-01 ถึง INV-187) พร้อมชื่อลูกค้าสมมุติ (คุณ A, คุณ B, บริษัท A บิวตี้ ฯลฯ รหัสลูกค้า C-01 ถึง C-30) ส่วนลด และภาษีมูลค่าเพิ่ม 7%
- **ระบบรายจ่ายและซื้อสินค้า (Purchases & Expenses):**
  - บันทึกการซื้อสินค้าเข้าคลัง 32 รายการ (รหัส PO-01 ถึง PO-32) จากคู่ค้าผู้ผลิต 6 แห่ง (รหัส S-01 ถึง S-06)
  - บันทึกค่าใช้จ่ายดำเนินงาน 38 รายการ (รหัส PV-01 ถึง PV-38) แยก 12 หมวดบัญชีมาตรฐาน (ค่าเช่า, เงินเดือน, ค่าโฆษณา, ค่าขนส่ง, สาธารณูปโภค ฯลฯ)
- **ระบบทะเบียนผู้ติดต่อ (Contacts / CRM):** ทะเบียนลูกค้า 30 ราย และคู่ค้าผู้ผลิต 6 ราย พร้อมสรุปยอดซื้อสะสมและยอดหนี้คงค้าง
- **แดชบอร์ดและกราฟวิเคราะห์ (Dashboard & Analytics):**
  - สรุปตัวเลขทางการเงิน 10 กล่อง (ยอดขายสุทธิ, ต้นทุนขาย, กำไรขั้นต้น, กำไรสุทธิ, สต็อกคงเหลือ, ลูกหนี้, เจ้าหนี้)
  - สรุปสถานะการเงิน บัญชีเงินฝากธนาคาร (กสิกรไทย, ไทยพาณิชย์, เงินสดในมือ) และสรุปภาษีมูลค่าเพิ่ม ภ.พ.30 สไตล์ PEAK / FlowAccount
  - กราฟแคนวาสแบบย้อนยุค 4 ด้าน (เปรียบเทียบรายได้รายเดือน, สัดส่วนค่าใช้จ่าย, 7 อันดับสินค้าขายดี, สัดส่วนช่องทางชำระเงิน)
- **งบการเงินฉบับสมบูรณ์ (Complete Financial Statements):**
  - งบกำไรขาดทุนเบ็ดเสร็จ (Income Statement)
  - งบแสดงฐานะการเงิน (Balance Sheet) ดุลสมบูรณ์ สินทรัพย์ = หนี้สิน + ส่วนของเจ้าของ (ผลต่าง 0.00 บาท)
  - งบทดลอง (Trial Balance) เดบิต = เครดิต (6,239,477.89 บาท)
  - ผังบัญชีมาตรฐาน 5 หมวด (Chart of Accounts)
- **ฟังก์ชันการใช้งาน:**
  - รองรับการใช้งานทั้งบนคอมพิวเตอร์และโทรศัพท์มือถือ (Mobile Responsive)
  - ขนาดตัวอักษรอ่านง่าย สบายตา
  - ระบบค้นหาและตัวกรองข้อมูลแบบ Real-time
  - การแบ่งหน้า (Pagination) 25 รายการ / หน้า หรือเลือกแสดงครบ 100 รายการ
  - ส่งออกข้อมูลในตารางเป็นไฟล์ CSV สำหรับเปิดใน Microsoft Excel (รองรับภาษาไทยสมบูรณ์ด้วย UTF-8 BOM)
  - สั่งพิมพ์รายงาน (Print Preview) ที่จัดรูปแบบหน้ากระดาษอย่างเป็นระเบียบ

### กฏเหล็กที่ปฏิบัติตามอย่างเคร่งครัด
1. **ปราศจากอิโมจิ 100% (No Emojis):** ใช้สัญลักษณ์ข้อความและแท็กมาตรฐาน เช่น `[OK]`, `[!]`, `[INV]`, `[PO]`, `[PV]`, `(Dr.)`, `(Cr.)`
2. **สไตล์ตาราง HTML แบบโบราณ:** ใช้โครงสร้างตารางขอบนูน/ขอบยุบ (Bevel Borders) โทนสีและฟอนต์ยุคคลาสสิก (Tahoma / MS Sans Serif / Courier New)
3. **ความเป็นมนุษย์และภาษาทางการบัญชี:** ถ้อยคำ เอกสาร และการบันทึกบัญชีอิงตามมาตรฐานการรายงานทางการเงิน NPAEs และระบบสารสนเทศทางการบัญชี (AIS) ของนักศึกษา

### วิธีการนำขึ้น GitHub Pages (Deployment Steps)

1. **สร้าง Git Repository ภายในโฟลเดอร์นี้:**
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Bowie Scareskin General Accounting System"
   ```

2. **เชื่อมต่อไปยัง GitHub Repository ของคุณ:**
   ```bash
   git branch -M main
   git remote add origin https://github.com/<USERNAME>/<REPO_NAME>.git
   git push -u origin main
   ```

3. **เปิดใช้งาน GitHub Pages:**
   - เข้าไปที่หน้า Repository บน GitHub -> **Settings**
   - ไปที่เมนูด้านซ้ายเลือก **Pages**
   - ในหัวข้อ **Build and deployment > Source** ให้เลือก **Deploy from a branch**
   - ในหัวข้อ **Branch** ให้เลือก `main` โฟลเดอร์ `/ (root)` แล้วกด **Save**
   - รอ 1-2 นาที เว็บไซต์จะเปิดให้บริการที่ URL: `https://<USERNAME>.github.io/<REPO_NAME>/`
